# lab_1

Під час аналізу набору даних було встановлено, що найбільш помітний зв’язок із кількістю людей у приміщенні мають показники освітлення та концентрації CO₂. Зі збільшенням кількості людей значення цих параметрів помітно змінюються, тому вони є інформативними для визначення заповненості приміщення. Датчики руху PIR також дозволяють визначати присутність людей, однак їх показники є менш конкретними для визначення точної кількості осіб. Температурні та звукові показники також мають певний зв’язок із заповненістю приміщення, але він є менш вираженим. Загалом отримані результати відповідають очікуваним закономірностям для даного набору даних.
